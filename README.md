# 抖音视频下载器

[![Tests](https://github.com/SolitudeSailor/douyin-download/actions/workflows/tests.yml/badge.svg)](https://github.com/SolitudeSailor/douyin-download/actions/workflows/tests.yml)

一个本地运行的抖音视频下载工具，支持单个作品和用户主页批量下载。

> 仅限个人学习与自有内容备份。请遵守平台规则和相关法律，不要下载或传播未经授权的内容。

## 功能

- 单个视频和用户主页批量下载
- 分享文本、短链、作品页、图文页和精选页链接解析
- 批量数量及日期范围筛选
- 增量下载，自动跳过已存在的文件
- 自定义文件名和实时任务进度
- 本地运行，服务仅绑定 `127.0.0.1`

## 快速开始

1. 从 [Releases](https://github.com/SolitudeSailor/douyin-download/releases) 下载 `douyin-tool.exe`，放到固定文件夹。
2. 双击运行。首次启动通常需要 5～15 秒，请勿重复点击。
3. 点击「打开登录窗口」，在弹出的专属浏览器中完成抖音登录。
4. 粘贴作品链接、分享文本或用户主页链接。
5. 选择下载方式后点击「开始下载」，在任务区域查看进度。

首次登录后会自动保存登录状态，失效时重新登录即可。详细操作见 [使用说明](docs/使用说明.md)。

## 下载说明

- 单个作品：粘贴作品链接或完整分享文本。
- 批量下载：粘贴用户主页链接，可限制数量和日期范围。
- 默认自动跳过已经下载且文件仍存在的作品。
- 勾选「强制重新下载」后，成功时替换旧文件，失败时保留原文件。
- 视频默认保存在 EXE 同级的 `Download/` 目录。

## 常见问题

| 问题 | 处理方法 |
| --- | --- |
| 提示未登录或返回 403 | 点击「打开登录窗口」重新登录 |
| 登录窗口没有出现 | 检查任务栏；关闭之前打开的专属浏览器后重试 |
| 找不到浏览器 | 安装 Microsoft Edge 或 Google Chrome |
| 下载 0 条且没有明确错误 | 降低批量数量、稍后重试或更换网络 |
| 提示文件已存在 | 文件仍在下载目录；需要覆盖时勾选「强制重新下载」 |
| 没有生成视频文件 | 作品可能是图文、私密、已删除或受平台限制 |
| 杀毒软件提示风险 | PyInstaller 单文件程序可能误报，可使用源码自行构建 |

## 数据与安全

程序会在 EXE 同级目录保存：

- `config.yaml`：设置和登录 Cookie
- `browser_profile/`：专属浏览器登录状态
- `Download/`：下载的视频
- `logs/`：运行日志

这些内容包含登录状态或个人使用记录，请勿上传或分享。仓库的 `.gitignore` 已排除相关运行数据。

安全问题及报告方式见 [SECURITY.md](SECURITY.md)。
