========================================
   抖音视频下载器  ·  使用说明
========================================

【这是什么】
把你喜欢的抖音视频保存到自己电脑里。
  · 粘一个视频链接    → 存这一个
  · 粘一个作者主页链接 → 批量存这个作者的作品

下载的是无水印视频，文件名形如：日期_作者_文案.mp4

----------------------------------------
【量 一 下：三步上手】
----------------------------------------

第 1 步  登录（只需一次）
  1) 双击「抖音视频下载器」
  2) 操作界面会在程序自己的窗口里打开
     （没有浏览器地址栏和标签栏，就像普通桌面软件一样；
       按住顶部标题栏可以拖动窗口，双击标题栏可以最大化 / 还原，
       右上角有最小化 / 最大化 / 关闭；最大化之后按 Esc 键即可还原）
     注意：双击之后屏幕上会安静几秒（5~15 秒），这是正常的。
       程序先把窗口藏起来，等界面画好了再一次性亮出来 ——
       你看到窗口的那一刻，内容就已经在里面了，不会一片空白。
       所以别急着再点第二次（重复双击不会再开一个）。
  3) 点界面上的「打开登录窗口」
  4) 弹出的独立浏览器窗口里，用抖音 App 扫码登录
  5) 登录成功后窗口自动关闭，界面显示「已登录」

  这个窗口和你平时用的浏览器完全隔离，
  不会读取、也不会影响你已有的账号、书签和浏览记录。

第 2 步  复制链接
  在抖音里找到想保存的视频 → 点「分享」→「复制链接」。
  用电脑也可以直接复制作品页地址栏里的网址。

第 3 步  粘贴下载
  链接粘进输入框 → 点「解析」→ 确认信息无误 → 点「开始下载」。

----------------------------------------
【哪些链接都认】
----------------------------------------
  分享文本    https://v.douyin.com/xxxx/
  作品页      https://www.douyin.com/video/7xxxxxxxxxx
  精选页      https://www.douyin.com/jingxuan?modal_id=7xxxxxxxxxx
  作者主页    https://www.douyin.com/user/MS4wLjAB...
  图文作品    https://www.douyin.com/note/7xxxxxxxxxx
  只知道 ID   直接填 7xxxxxxxxxx

  一句话：抖音里能打开这条作品的地址，整段粘进来就行，不用改。

----------------------------------------
【批量下载某个作者】
----------------------------------------
  1) 电脑浏览器打开作者主页，复制地址栏的完整链接
  2) 粘贴 → 解析 → 界面会提示识别到「用户主页」
  3) 设置条数（默认 20）
  4) 可填日期区间筛选，例如 2025-01-01 到 2025-12-31
  5) 点「开始下载」

  提示：一次别拉太多，容易触发风控，建议分批下。
  注意：主页地址里若带 ?modal_id=… ，会被识别成「那一条作品」，
       想批量就把 ? 后面的内容删掉。

----------------------------------------
【文件存哪儿】
----------------------------------------
  默认存在程序目录下的 Download 文件夹，
  界面上有「打开下载目录」按钮可以直接跳过去。
  同一作者的作品会归类到同一个子文件夹里。

----------------------------------------
【重复下载会不会存成两份】
----------------------------------------
  不会。程序会记住下过哪些视频，而且每次都会确认文件还真的在。
    · 文件还在    → 自动跳过，只下新的
    · 文件被删了  → 下次自动重新下载
  想强制重下一遍，勾上「强制重新下载」再点开始。

----------------------------------------
【怎么退出程序】
----------------------------------------
  点窗口右上角的「关闭」（或 Alt+F4）就行，程序会跟着自己退出，
  不会在后台留一堆进程。

  想再打开：重新双击程序图标即可。
  它不会重复启动第二份，只会把已有的那个窗口叫到最前面。

  正在下载时点关闭会弹一次确认，防止手滑把任务中断掉。

----------------------------------------
【常见问题】
----------------------------------------
  双击之后半天没动静？
    首次启动需要自我解压、把界面画好，全程 5~15 秒；
    这段时间屏幕上不会有窗口，等窗口出现时界面已经是完整的了。
    超过 30 秒仍无窗口，检查杀毒软件是否拦截。

  杀毒软件报警？
    PyInstaller 打包程序的通病，程序本身无恶意行为，加入信任即可。

  提示「未找到 Chrome 或 Edge」？
    需要电脑上装了 Chrome 或 Edge 其中之一（任一款即可）。

  提示 403 或下载 0 条却无报错？
    多半是登录态过期：点「打开登录窗口」重新登录一次。
    如果刚登录成功仍然失败，说明程序版本需要更新。

  界面窗口没出来？
    极少数电脑缺 WebView2 运行时会这样，程序会自动改用系统浏览器打开
    （老版本的行为）。也可以手动在浏览器输入日志里的地址
    （形如 http://127.0.0.1:xxxx）。

  想看错误日志？
    程序目录下 logs\error.log，里面记录了详细原因。

  关掉窗口了，任务管理器里还能看到 douyin-tool.exe？
    正常。它正在清理自己解压出来的临时文件（约 50MB），
    十几秒后会自动消失，不会一直留着占内存。
    同一个程序也只会有一份在跑，重复双击不会再堆进程。

  点登录按钮没看到窗口？
    可能开在了屏幕外或被最小化，检查一下任务栏。
    如果提示「超时」，关掉所有本程序打开的浏览器窗口再点一次。

----------------------------------------
【几点说明】
----------------------------------------
  · 程序只在本机运行，所有数据都在你自己电脑上，不上传任何服务器。
  · 程序目录里的 config.yaml 和 browser_profile 文件夹
    保存着你的登录凭证，请不要分享给他人。
  · 首次运行会自动生成配置，你不需要手动创建任何文件。

  祝使用愉快 :)
