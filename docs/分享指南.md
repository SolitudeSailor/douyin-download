# 怎么把工具分享给别人

## 一、发哪个文件

分享包默认生成在项目的 **`release/`**，里面有两个产物，任选一个发：

| 文件 | 适合谁 | 说明 | 大小 |
| --- | --- | --- | --- |
| `抖音视频下载器-安装程序.exe` | 不太懂电脑的人 | 双击 → 下一步 → 完成。自动建桌面与开始菜单快捷方式，可从系统「设置 → 应用」里卸载 | 约 29 MB |
| `抖音视频下载器-绿色版.zip` | 懂电脑的人 / 想放 U 盘 | 解压到任意文件夹，双击里面的 exe 就能用。不写注册表，删掉文件夹即卸载干净 | 约 27 MB |

安装程序默认装到 `C:\Users\<对方的用户名>\DouyinDownloader`，
**不需要管理员权限，也不会弹 UAC**。这个位置是刻意选的 ——
程序运行时要在自己旁边生成登录态和下载目录，装进 `C:\Program Files` 会因没有写权限而失败。

## 二、怎么传

微信 / QQ / 钉钉 / 网盘都行，直接发上面那**一个文件**。

几个注意点：

- **只发那一个文件，别整个文件夹发。** 尤其是别发 `dist/`、`data/` 或 `secure/` —— 前两个里面有你的账号登录态，后者是凭据的加密归档。
- **分享目录里只放那两个产物，别把任何说明文档（包括本指南）拷进去。** 本指南里写了你的用户名和本机路径，混进去等于把自己的信息一起带走。目前该目录已通过审计，是「整个文件夹发出去也安全」的状态。
- 微信有时会拦 exe（提示「可能含风险文件」），那就改发 zip 版。
- 单个文件 27~29 MB，微信/QQ 直接传没问题。

## 三、为什么不会泄露你的信息

生成分享包时跑过一次完整审计（`build/audit_release.py`），结果：

| 检查项 | 结果 |
| --- | --- |
| 打包素材是否夹带运行时数据 | 无（进包清单写死只允许 2 个文件） |
| exe 二进制里是否有你的用户名 / 本机路径 | 无 |
| 产物里是否有真实 Cookie 片段 | 无 |
| 安装程序的版本资源（CompanyName / LegalCopyright 等） | 全部为空 |

几个关键事实：

- **exe 是从 `src/` 重新编译的二进制**，发布前审计会扫描本机用户名、用户目录、项目绝对路径和 Cookie 值，任一命中都会失败。
- **分享包里不含 `config.yaml`**。程序首次运行会用内置默认值自动生成一份空配置，Cookie 字段是空的。
- **不含 `browser_profile`**（登录态）、**不含 `Download`**（你下的视频）、**不含下载记录**。
- 安装程序的 `AppPublisher` / `AppCopyright` 等字段**留空**，不会写入任何可识别信息。

> 每次重新生成分享包后，都建议跑一遍（不通过会以非 0 退出码结束）：
>
> ```bat
> rem 审计打包工作区
> python build\audit_release.py
>
> rem 审计搬走后的最终分享目录
> python build\audit_release.py "%DOUYIN_SHARE_DIR%"
> ```

## 四、对方拿到后怎么用

**安装程序版**：双击 → 选目录（默认即可）→ 下一步 → 完成 → 桌面出现「抖音视频下载器」。
**绿色版**：解压 → 双击文件夹里的 exe。

之后都一样：

1. 浏览器自动打开界面
2. 点「打开登录窗口」，在弹出的窗口里用抖音 App 扫码登录（只此一次）
3. 粘贴视频链接（或作者主页链接）→ 解析 → 下载

包里附了一份 `使用说明.txt`，对方自己看就行。

## 五、以后想重新生成分享包

```bat
build\build_installer.bat
```

它会依次：编译安装程序 → 打包绿色版 → 自动复制到分享目录。

**如果你改了代码，要先重新打包主程序，再生成分享包：**

```bat
rem 1) 重新编译主程序 → dist\douyin-tool.exe
build\build.bat

rem 2) 生成分享包（直接取 dist 里的新 exe）+ 审计
build\build_installer.bat
python build\audit_release.py
```

> 打包脚本直接读 `dist\douyin-tool.exe`，**没有中间副本**，
> 所以不存在「忘记同步 → 发出去的是旧版」这种问题。

## 六、目录说明

```
dist/
  douyin-tool.exe     ★ 唯一的主程序（build.bat 产物，也是打包素材来源）

build/
  installer.iss       安装程序脚本（Inno Setup）
  build_installer.bat 一键：编译安装程序 + 打绿色包 + 同步到分享目录
  make_portable.py    打绿色包（显式文件清单，不扫目录）
  audit_release.py    发布前安全审计（可指定目录）
  使用说明.txt         面向接收者的说明（打包素材）

release/              打包输出（生成后会自动同步到分享目录；不打时不存在）
  抖音视频下载器-安装程序.exe
  抖音视频下载器-绿色版.zip

%DOUYIN_SHARE_DIR%\                ★ 可选的最终对外分享目录，只放这两个文件
  抖音视频下载器-安装程序.exe
  抖音视频下载器-绿色版.zip
```

> 全项目只有**一个** douyin-tool.exe（在 `dist\`）。不要为了"干净"再复制一份
> 到别处当发布源 —— 副本一多，迟早分不清哪份是新的。

## 七、你自己的凭据怎么保管

项目根新增了 `secure/` —— **凭据保险箱**。它把 `config.yaml`（含登录 Cookie）、
`browser_profile/`（登录态）、下载记录等打包成一个 **AES-256 加密 + 文件名加密**的
`vault.7z`，密码你自己设。

```bat
secure\seal.bat              rem 封存：加密归档（默认不删明文）
secure\seal.bat --purge      rem 真锁起来：归档后抹掉原位明文
secure\unseal.bat            rem 解封：还原回原位，程序才能跑
```

> 因为 exe 运行时**必须直接读到明文**的 Cookie 和登录态，所以加密是
> **你主动按下的一个动作**，而不是常态：日常开发保持解封，离开电脑 /
> 存档 / 备份前跑一次 `seal.bat --purge` 即可。
>
> 详细说明见 `secure/README.md`。
