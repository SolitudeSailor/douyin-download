# 开发指南

## 环境初始化

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
```

安装后可使用 `python -m douyin_tool` 或 `douyin-tool` 启动。运行时数据统一写入
`data/`，不会污染源码目录。

## 目录职责

```text
src/douyin_tool/       可安装的应用包
  cli.py               命令行与程序入口
  web_app.py           Flask Blueprint、应用工厂和服务启动
  core.py              下载用例与 f2 适配
  config.py            配置、路径和下载历史
  storage.py           原子写入与文件锁
  validation.py        无外部依赖的输入校验
  browser_login.py     CDP 登录流程
  cookie_reader.py     浏览器与 Cookie 解析
  console.py           日志和无控制台兼容
  win_window.py        Windows 桌面窗口适配
  web/                 随 Python 包分发的模板与静态资源
tests/                  离线回归与本地服务测试
build/                  PyInstaller 和发布脚本
docs/                   用户、架构和诊断文档
data/                   本地运行数据（不入库）
```

依赖方向应保持为：入口/界面 → 用例与校验 → 配置/存储/外部适配。新增业务规则优先
放入无 Flask、无窗口依赖的模块，避免让 `web_app.py` 成为唯一实现位置。

## 验证

```powershell
.\.venv\Scripts\python.exe tests\run_all.py
```

测试套件默认隔离数据目录并阻止外网访问。涉及打包的专项验证仍按 `tests/README.md`
执行。
