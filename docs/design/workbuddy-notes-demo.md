# WorkBuddy 视频笔记前端 Demo

双击同目录的 `workbuddy-notes-demo.html`，使用 Chrome 或 Edge 打开。无需启动 Flask、安装依赖或连接网络。

## 体验顺序

### 快速体验（推荐）

1. 点击“一键体验示例”。
2. Demo 自动模拟整理过程，并跳转到生成后的笔记结果。
3. 切换阅读与 Markdown 预览，可复制结果路径或下载示例笔记。

### 正式接入演示

1. 点击“正式接入设置”。
2. 查看技能导入步骤并导出示例 ZIP。
3. 填写 Obsidian 仓库绝对路径，选择笔记模板并核对设置。
4. 从视频卡片准备任务；任务指令默认折叠在高级信息中。

## 范围

- 纯 HTML、CSS、JavaScript，保留现有软件的暖白和陶土色风格；支持窄屏和深色主题。
- 体验模式与正式接入设置明确分开；首次进入不会被配置向导阻断。
- 设置保存在当前浏览器的 localStorage 中；“重置演示”清除本页演示状态。
- WorkBuddy 打开和笔记生成都是模拟，不执行视频下载、转写、API 请求或知识库写入。
- 技能 ZIP、任务说明及示例 Markdown 通过浏览器下载，保存位置由浏览器决定。
- ZIP 中的 `video-notes-demo` 是独立示例技能，只整理用户指定的已有逐字稿；没有语音转写程序，也不会自动导入或覆盖现有 `video-to-text-notes` 技能。
- 初始视频元信息来自项目已有样例。笔记内容和时间戳用于展示格式，未在此 Demo 中重新识别或核对。
