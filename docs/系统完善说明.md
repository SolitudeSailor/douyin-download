# 系统完善说明

日期：2026-10-06。适用于当前源码；旧架构报告保留为历史快照。

## 已修复的问题

| 问题 | 当前行为 |
| --- | --- |
| 强制下载仍被 f2 跳过 | 先写入作者目录中的独立临时目录；成功后同盘原子替换视频，失败/取消保留旧文件 |
| 取消只改提示，不中止传输 | 排队时不启动下载；运行中取消整个协程链并等待收尾，状态为 cancelled |
| 未生成文件却显示成功 | 单视频返回失败；批量统计失败作品，全部失败的任务显示失败；CLI 有失败时返回非零退出码 |
| 多线程共享 f2 全局组件 | 同一服务串行执行下载，待完成任务上限 20，旧的已结束任务保留约 100 条 |
| JSON/YAML 并发覆盖或写入中断 | 整个读改写事务加线程及进程锁，临时文件刷新后原子替换目标文件 |
| 保存失败仍回显成功 | 持久化异常向调用层传递，Web 返回失败，登录状态明确显示保存失败 |
| f2 Handler 额外连接泄漏 | 信息获取、下载、失败和取消分支统一关闭其下载器；协程退出时回收子任务 |
| 并发打开多个登录窗口 | 登录状态检查与启动占位在同一个锁中，取消后收到的 Cookie 不再保存 |
| 错误参数变成无限量任务 | 模式、数量、布尔值、日期及日期顺序先校验；0 与省略参数分别处理 |
| 模板或跨站请求操作本地服务 | 校验命名占位符和路径字符；限制 API Host/Origin，拒绝非对象 JSON；不回显 Cookie 片段 |
| 测试修改真实数据或隐式联网 | 临时数据目录隔离；替换测试令牌请求并阻止外网；统一 UTF-8 和脚本超时 |
| 环境只在原电脑可用 | 声明 pywebview/WebSocket 直接依赖，固定直接依赖版本，生成完整 Windows 依赖快照，打包解释器可配置 |
| 发布程序夹带源码缓存路径 | Python 模块只进入 PYZ，不再把整个 src 目录当普通资源；先构建并深度审计候选 exe，再替换主程序 |

## 开发与验证

推荐 Windows + Python 3.13：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[dev]"
.\.venv\Scripts\python.exe tests/run_all.py
.\.venv\Scripts\python.exe -m douyin_tool
```

如需严格复现已验证依赖版本，再使用 `requirements-lock.txt` 覆盖安装；其他平台的
界面会在系统浏览器中打开。
运行时配置与下载历史保留原有 YAML/JSON 格式；`.lock` 是本地互斥文件，
程序退出时操作系统释放锁，文件可留在原位。

`DOUYIN_DATA_DIR` 现在同时支持源码和 exe，适合独立测试与数据目录迁移。
没有设置时保持原有位置：源码使用 `data/`，exe 使用同级目录或 `data_dir.txt` 指针。

依赖快照包含运行和打包依赖的闭包，由当前兼容环境生成：

```powershell
.\.venv\Scripts\python.exe build/lock_dependencies.py
build\build.bat
```

更新依赖后先跑测试，再重新生成快照。快照包含 Windows/Python 3.13 环境的
70 个依赖固定版本，生成器会拒绝缺失包或已发现的版本冲突。
