## 0. 先泼盆冷水：你给的那个链接抓不到东西

你给的 `https://www.douyin.com/?recommend=1` 是抖音**网页版推荐流首页**。
实测未登录状态下访问，返回的只是一张"下载 APP / 充钻石"的引导页，
没有任何视频数据。原因：

- 推荐流是**登录态 + 个性化**接口（`/aweme/v2/web/module/feed/`），需要 Cookie 与签名；
- 抖音对 Web 端接口做了强风控，裸 HTTP 请求返回空数据或错误码。

**结论：爬抖音的基本单位不是"首页"，而是"单个作品"或"某个用户的作品列表"。**
下面的文档就围绕这个来。

## 1. 抖音反爬机制全景（2026 年现状）

做抖音爬虫，必须先知道你在跟什么斗。抖音用的是字节自研的风控体系（不是 Cloudflare 那类第三方 WAF）：

| 防线 | 说明 | 难度 |
|---|---|---|
| **a_bogus 签名** | 当前主力。由浏览器里的 JS 虚拟机计算，输入是 **URL 查询串 + User-Agent**。缺了它，接口返回空/报错 | ★★★★★ |
| **X-Bogus（旧）** | 2024 年 6 月前的签名，现仅部分老接口还在用 | ★★★★ |
| **msToken** | 会话令牌，约 15 分钟过期，需动态获取 | ★★★ |
| **ttwid** | 设备追踪标识，通过注册接口获取，长期有效 | ★★ |
| **webid / s_v_web_id** | Web 客户端标识 | ★★ |
| **TLS 指纹** | 标准 Python requests 的握手指纹可被识别，需 curl_cffi 模拟 Chrome | ★★★ |
| **IP 信誉** | 机房 IP 段被默认拉黑，需国内住宅 IP / 4G 代理 | ★★★★ |
| **限流** | 触发后不是报错，而是**静默返回 0 条**（最难排查） | ★★★ |

**分级理解（很重要）：**

- **热点榜 / 公开话题数据**：**无需签名、无需代理**，直接 GET 就能拿。约 2/5 难度。
- **登录态接口**（用户主页、搜索、评论、收藏）：真·4~5 难度，必须突破签名 + 令牌 + IP。

## 2. 三种技术路线（按投入产出排序）

### 路线 A：浏览器抓包复用（零逆向，学习首选）★ 推荐入门

不实现任何签名算法，直接在真实浏览器里拿"已经算好签名的完整请求"。

**操作步骤：**

1. Chrome 打开 `https://www.douyin.com`，**登录**你的账号；
2. 随便点开一个视频，按 `F12` 打开 DevTools → 切到 **Network** 面板；
3. 筛选框输入 `aweme/detail`，刷新页面，找到那条请求；
4. 右键该请求 → **Copy → Copy as cURL (bash)**；
5. 把 cURL 粘到 [curlconverter.com](https://curlconverter.com)，一键转成 Python 代码；
6. 你手里就有了**完整可用的请求**（含 Cookie、a_bogus、所有参数）。

想批量，就把 cURL 里的 `aweme_id` 换掉重发——但注意 a_bogus 与 URL **强绑定**，
改了参数签名就失效，所以批量场景还得看路线 B。

> 本项目的 `docs/reference/douyin_downloader.py` 就走这条路线：你提供 Cookie，
> 它负责 短链解析 → 详情接口 → 挑无水印地址 → 下载。

### 路线 B：调用开源库（工程化，最省事）★★ 推荐实战

社区已有成熟实现，签名、令牌、代理轮换全帮你处理好了：

| 项目 | 说明 | 地址 |
|---|---|---|
| **f2** | **当前活跃维护的参考实现**，纯 Python 的 ABogusManager / XBogusManager，含全套令牌管理 | `github.com/Johnserf-Seed/f2` |
| **TikTokDownloader** | 出道早、功能全，支持用户作品/喜欢/收藏/图文/音频批量下载 | `github.com/JoeanAmier/TikTokDownloader` |
| **Douyin_TikTok_Download_API** | 一个封装好的 Web API，起服务就能用 | `github.com/Evil0ctal/Douyin_TikTok_Download_API` |

用法（以 f2 为例）：

```bash
pip install f2
f2 dy -u "https://v.douyin.com/xxxx/" -m post
```

> 想省事的直接用这些，别自己造签名轮子——a_bogus 算法字节会改版，
> 自己维护成本极高。

### 路线 C：自己逆向签名（深度研究用）★★★★★ 不推荐

需要拆 JS 混淆、复现 SM3+RC4 签名流程。学习价值高，但工程性价比低。
签名流程概要（供理解原理）：

```
输入: [URL查询串] + [User-Agent] + [时间戳] + [固定魔数]
  -> SM3 哈希 / MD5 特征字节
  -> 组装字节数组 + 异或校验
  -> RC4 加密 + 自定义 Base64
  -> 拼接前缀 -> a_bogus
```

## 3. 核心接口速查表

基础域名：`https://www.douyin.com`

| 功能 | 方法 | 端点 | 关键参数 |
|---|---|---|---|
| 作品详情（单视频） | GET | `/aweme/v1/web/aweme/detail/` | `aweme_id`, `aid=6383`, `device_platform=webapp` |
| 批量作品详情 | POST | `/aweme/v1/web/multi/aweme/detail/` | `aweme_ids` |
| 推荐 Feed 流 | POST | `/aweme/v2/web/module/feed/` | `module_id=3003101`, `count=20` |
| 热搜榜 | GET | `/aweme/v1/web/hot/search/list/` | 无特殊要求 |
| 搜索建议 | GET | `/aweme/v1/web/search/sug/` | `keyword` |
| 评论列表 | GET | `/aweme/v1/web/comment/list/` | `aweme_id`, `cursor`, `count` |
| 用户作品列表 | GET | `/aweme/v1/web/aweme/post/` | `sec_user_id`, `max_cursor`, `count` |

**详情接口返回中，你要的字段：**

```jsonc
{
  "aweme_detail": {
    "aweme_id": "...",
    "desc": "视频文案",
    "author": { "nickname": "作者名", "sec_uid": "..." },
    "video": {
      // 无水印地址在这里（Web 端返回的通常就是无水印源）
      "play_addr":  { "url_list": ["https://...mp4", "https://...mp4"] },
      "bit_rate": [                      // 多清晰度候选
        { "bit_rate": 2000000, "play_addr": { "url_list": ["..."] } }
      ],
      "cover": { "url_list": ["封面图"] }
    },
    "music": { "title": "背景音乐" },
    "statistics": { "digg_count": 点赞, "comment_count": 评论, "share_count": 分享 }
  }
}
```

> 关键认知：**Web 端接口返回的 `play_addr` 就是无水印的**。
> 所谓"去水印工具"大多就是在做同一件事：取这个地址而已。

## 4. 本项目代码说明

### 文件

```
docs/reference/douyin_downloader.py     # 单文件下载器，含完整注释
```

> 这是随文档一起保留的**教学骨架**（不实现签名），与主程序 `src/` 无关，
> 所以放在 `docs/reference/` 而不是 `src/`。

### 安装依赖

```bash
# 用托管 Python 建虚拟环境
"<python.exe>" -m venv C:/Users/<你>/.workbuddy/binaries/python/envs/default
C:/Users/<你>/.workbuddy/binaries/python/envs/default/Scripts/pip.exe install requests
```

### 获取 Cookie（必须）

1. 浏览器登录 `douyin.com`；
2. F12 → Network → 任意请求 → Headers → 复制 `Cookie:` 整行；
3. 关键字段：`ttwid`、`msToken`、`__ac_nonce`、`__ac_signature`、`sessionid`。

### 运行

```bash
# 方式一：命令行传 Cookie
python docs/reference/douyin_downloader.py "7.43 复制打开抖音... https://v.douyin.com/xxxx/" -c "你的Cookie"

# 方式二：环境变量（推荐，避免命令历史泄露）
export DOUYIN_COOKIE="你的Cookie"
python docs/reference/douyin_downloader.py "https://v.douyin.com/xxxx/" -o downloads
```

### 执行链路

```
分享文本  ──extract_url──▶  短链 URL
         ──resolve_aweme_id──▶  数字 aweme_id
         ──fetch_aweme_detail──▶  结构化详情 JSON
         ──pick_play_urls──▶  无水印候选地址列表
         ──download──▶  downloads/<aweme_id>.mp4 + .json
```

## 5. 常见问题排查

| 现象 | 原因 | 解决 |
|---|---|---|
| `status_code: 8` / 空数据 | 缺签名或 Cookie 失效 | 重取 Cookie；改用路线 B 的开源库 |
| `aweme_list` 为空但 HTTP 200 | **触发风控静默限流**（最坑） | 换住宅 IP / 降频 / 换账号 |
| 403 Forbidden | Referer 缺失或 IP 被拒 | 补 `Referer: https://www.douyin.com/`，换国内 IP |
| 下载到 0 字节 | CDN 防盗链 | 下载时必须带 `Referer`，见代码注释 |
| 短链解析不出 id | 短链失效 / 跳转页改版 | 用分享文本整体传入，或直接从链接取 `modal_id` |
| TLS 握手被识别 | requests 指纹特征明显 | 换 `curl_cffi`（`impersonate="chrome"`） |

## 6. 合规红线（不是吓唬你）

- **《个人信息保护法》(PIPL)**：用户画像、行为数据属个人信息，未经同意抓取即违法，
  最高罚款 **5000 万元或年营收 5%**。
- **2025 年《网络安全法》修订**：强化了跨境执法，境外主体同样适用。
- **抖音用户协议**：明确禁止未经许可的自动化数据采集。

**实操边界：**

- ✅ 下载自己的作品做备份
- ✅ 学习签名原理、做技术研究（小样本、不传播）
- ❌ 批量抓取他人作品/评论/粉丝数据
- ❌ 抓取并存储用户个人信息
- ❌ 商业分发、二次售卖数据
