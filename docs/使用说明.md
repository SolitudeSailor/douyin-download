# 使用说明（图文版）

面向第一次使用的人。全程只需要一个文件：`douyin-tool.exe`。

---

## 一、这个东西是干嘛的

把抖音上的视频存到你自己电脑里。

- 粘贴一个视频链接 → 存这一个
- 粘贴一个作者主页链接 → 把这个作者的作品批量存下来

下载的是**无水印视频**，文件名格式是 `日期_作者_文案.mp4`，方便你后续查找。

---

## 二、怎么用（三步）

### 第 1 步：把它放到一个固定的文件夹

比如 `D:\抖音下载\`。

> **为什么要固定？** 程序会在 exe 旁边生成 `config.yaml`（存你的登录信息）
> 和 `Download\`（存视频）。换个位置放，配置和已下载记录就跟着搬走了。

把 `douyin-tool.exe` 放进去，双击。

**第一次双击会有点慢**（5～15 秒）。单文件 exe 需要先把自己解压到临时目录，
这是正常现象，不是卡死。

> **等这几秒时屏幕上不会出现任何窗口，这是刻意做的。**
> 程序先把窗口藏起来，等界面在后台画好了再一次性亮出来 —— 你看到窗口的那一刻，
> 内容就已经在里面了，不会出现「窗口开了但一片空白」。
> 所以双击后请给它几秒，别急着再点第二次：重复双击不会再开第二个，
> 程序会直接把你带回已经开着的那个。
>
> 真等久了想看看它在干什么：下次启动的日志在 `data\logs\app.log`，
> 里面记着「窗口已创建 → 窗口已显示 → 页面已渲染」每一步的耗时。

### 第 2 步：操作界面会在程序自己的窗口里打开

界面跑在程序自带的应用窗口里 —— **没有浏览器地址栏、标签栏**，就像一个普通的桌面软件。
顶栏可以按住拖动窗口（**双击顶栏**可最大化 / 还原），右上角有「最小化」「最大化」「关闭」三个按钮。

> **极少数电脑看不到这个窗口？** 说明缺 WebView2 运行时（Win11 一般自带），
> 程序会自动改用系统浏览器打开。也可以手动在浏览器输入日志里的地址
> （一般是 `http://127.0.0.1:xxxx`）。

> 界面只在本机可访问（绑定 `127.0.0.1`），局域网其他设备也打不开，
> 你的 Cookie 不会外泄。

### 第 3 步：登录抖音（只需一次）

**为什么要登录？** 抖音接口需要登录态，不登录会直接返回
`403 Uifid Not Found`，一条都下不了。

**怎么做（点一个按钮）：**

1. 点界面上的「**打开登录窗口**」
2. 会弹出一个**专属浏览器窗口**。它和你的日常浏览器**完全隔离** ——
   不会读取也不会影响你现有的账号、书签、浏览历史
3. 在这个窗口里，用**抖音 App 扫码**登录（也可以账号密码登录）
4. 程序检测到登录成功后会**自动读取登录态并保存**，窗口自动关闭，
   界面上方的小标签会变成「已登录」

之后**再也不用登录**，直接粘贴网址就能下载。

> **如果点按钮后没看到窗口？** 可能是它开在了屏幕外或最小化了，
> 检查一下任务栏。若 180 秒内没登录完会提示超时，再点一次即可。

> **想看进度？** 界面会实时显示「正在启动浏览器…」「请在窗口里登录…」
> 等状态文字。

> **换电脑或删掉 `browser_profile` 文件夹后**，需要重新登录一次。

> 如果你以前用过旧版本（粘贴 cURL 那种），直接改用这个按钮即可，
> 旧方式已移除。

> **用完了怎么退出？** 点窗口右上角的「关闭」（或 Alt+F4）就行，程序会跟着自己退出，
> 不会在后台留一堆进程。下次要用再双击图标 —— 它不会重复启动第二份，
> 只会把已有的那个窗口叫到最前面。正在下载时点关闭会弹一次确认，防止手滑中断。

## 三、开始下载

### 下载单个视频

1. 在抖音 App 里点「分享」→「复制链接」
2. 粘贴到工具输入框，点「解析」
3. 确认信息没错，点「开始下载」

**下面这些链接形式都认，直接整段粘贴即可：**

| 你从哪复制的 | 长什么样 |
|---|---|
| App 分享文本（推荐） | `7.43 复制打开抖音，看看【…】的作品 https://v.douyin.com/xxxx/ 复制此链接` |
| 电脑端作品页地址栏 | `https://www.douyin.com/video/7xxxxxxxxxx` |
| **精选/推荐页点开作品后的地址** | `https://www.douyin.com/jingxuan?modal_id=7xxxxxxxxxx` |
| 作者主页里点开某条作品 | `https://www.douyin.com/user/MS4wLjAB…?modal_id=7xxxxxxxxxx` |
| 图文作品 | `https://www.douyin.com/note/7xxxxxxxxxx` |
| 只要知道 ID | 直接填 `7xxxxxxxxxx` |

> 一句话：**只要是抖音里能打开这条作品的页面地址，粘进来就行**，
> 不用自己去改链接。（程序会先自己把作品 ID 抠出来，抠不到才联网跟随短链跳转。）

### 批量下载某个作者

1. 电脑浏览器打开该作者主页，复制地址栏的完整链接
   （形如 `https://www.douyin.com/user/MS4wLjAB...`）
2. 粘贴 → 解析 → 界面会提示识别到"用户主页"
3. 设置最大下载条数（默认 20）
4. 需要的话填日期区间，比如 `2025-01-01` 到 `2025-12-31`
5. 点「开始下载」

> **注意**：如果主页地址里带 `?modal_id=…`（说明你当时正开着某条作品），
> 程序会识别成**那一条作品**而不是整个主页。想批量就把 `?` 后面的内容删掉。

> **为什么默认只下 20 条？** 一次性拉太多会触发风控，可能导致账号被限流。
> 建议分批下，比如每天下 20 条。

---

## 四、视频存在哪

在 exe 旁边的 `Download\` 文件夹里。界面上的「打开下载目录」按钮可以直接跳过去。

同一作者的作品会放在同一个子文件夹里，文件名形如：

```
2025-03-15_某某某_今天天气不错.mp4
```

---

## 五、增量下载是什么意思

程序会记住你下过哪些视频，**并且每次都会真的去下载目录里确认文件还在不在**。

- 文件还在 → 自动跳过，只下新的。放心地定期重复运行，不用怕下重复。
- **文件被你删了 / 移走了 → 下次会重新下载**（界面会提示「文件已丢失，已重新下载」）。

所以「已下载」的标准是**文件此刻真的躺在下载目录里**，而不是"程序以前记过一笔"。

### 两个相关开关

| 位置 | 作用 |
|---|---|
| 下载卡片里的「**强制重新下载**」勾选框 | 忽略记录，即使文件还在也重下一遍 |
| 顶部「**清空下载记录**」按钮 | 清空全部记录。之后所有作品会重新校验：文件还在的秒跳过（不重传），被删的会重新下载 |

> ⚠️ 如果你把视频**改了名字或挪到别的文件夹**，程序会认不出来（记录里的文件名对不上了），
> 下次会重新下载一份。想避免的话，下载完就别动它。

## 六、遇到问题怎么办

| 现象 | 原因 | 怎么办 |
|---|---|---|
| 双击后等了几秒还没窗口 | 正常 —— 窗口是等界面画好才亮出来的 | 再等几秒；超过 15 秒去看 `data\logs\app.log` |
| 双击没反应 | 首次解压慢 / 被杀软拦了 | 等 15 秒；检查杀软是否拦截 |
| 提示「另一个实例仍占着启动锁」 | 上一个实例正在退出 | 程序会自己等，最长 12 秒；之后会照常启动 |
| 点了登录按钮没窗口 | 窗口开在屏幕外/被最小化 | 检查任务栏；或在后台进程里找 |
| 提示「调试通道启动超时」 | 上次登录窗口没关干净 | 关掉所有本程序打开的浏览器窗口，再点一次 |
| 提示「未找到 Chrome 或 Edge」 | 电脑没装 Chromium 内核浏览器 | 安装 Chrome 或 Edge（任一款） |
| 提示「等待登录超时」 | 180 秒内没完成登录 | 重新点「打开登录窗口」，尽快扫码 |
| 403 `Uifid Not Found` | 登录态过期，或抖音风控规则升级 | 先点「打开登录窗口」重新登录；若刚登录仍失败，说明需要更新程序版本 |
| 提示「本地已存在，跳过下载」 | 文件确实还在 | 想重下就勾「强制重新下载」，或删掉那个 mp4 再点一次 |
| 提示「没有生成视频文件」 | 图文作品 / 已被屏蔽 / 私密 | 换一条作品试试 |
| 下载 0 条但没报错 | 触发风控静默限流 | 减少条数、换个网络、过会儿再试 |
| 提示「已下载过，跳过」 | 增量功能生效了 | 关掉「跳过已下载」 |
| 网页打不开 | 端口被占用 | 重新双击，程序会自动换端口 |
| 杀毒软件报警 | PyInstaller 打包的程序通病 | 加入白名单（源码无恶意行为） |
| 关掉窗口后任务管理器里还有 `douyin-tool.exe` | 它在清理自己解压出来的临时文件 | 等十几秒，会自己消失；不会越堆越多 |
| 程序闪退 | 有未知错误 | 查看 exe 同级的 `logs\error.log` |

**崩溃时程序会弹出错误框**，里面写着日志文件的位置。把那个 `logs\error.log`
发出来基本就能定位问题。

## 七、注意事项

- **只用于个人学习和备份自己的作品。** 别拿去批量抓别人的隐私内容，
  也别做二次分发。
- 程序**只在本机运行**，所有数据（Cookie、视频、历史记录）都在你电脑里，
  不上传任何服务器。
- `config.yaml` 和 `browser_profile\` 里都有你的登录凭证，
  **不要分享给别人**，也不要把它们传到网上。
- 需要「退出登录」时，点界面上的「退出登录」按钮即可（会清除登录态）。

## 八、从源码运行（给想改代码的人）

```bash
# 以可编辑模式安装应用和开发依赖
C:/Users/<你>/.workbuddy/binaries/python/envs/default/Scripts/pip.exe install -e ".[dev]"

# 启动界面
python -m douyin_tool

# 命令行登录（打开浏览器窗口扫码）
python -m douyin_tool --login

# 命令行直接下载
python -m douyin_tool -u "https://v.douyin.com/xxxx/"
python -m douyin_tool -u "https://www.douyin.com/user/MS4wLjAB..." -M post --max-counts 20
```

自己改完重新打包：

```bash
build\build.bat
```
