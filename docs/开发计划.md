# 抖音视频爬取工具（Web 界面 exe）实施计划

## 一、目标

做一个**封装好的抖音视频自动爬取小程序**，最终交付一个**单文件 `.exe`**：
双击自动开浏览器 → 网页里粘贴链接 / Cookie → 点击下载 → 实时看进度 → 文件落地。

定位：**签名与接口层交给 f2 开源库，我们只做"封装层"**——把 f2 包成一个普通人能用的工具。

## 二、已确认的关键决策

| 项 | 决定 |
|---|---|
| 签名方案 | 依赖开源库 **f2**（不自己实现 a_bogus） |
| 抓取范围 | 单视频 + 用户主页批量 |
| 形态 | **Web 界面 exe**（Flask + 自动开浏览器） |
| 打包 | **单文件 exe**（PyInstaller `--onefile`） |
| exe 命名 | **`douyin-tool.exe`**（英文名） |
| 旧骨架 | `docs/reference/douyin_downloader.py` **保留**作教学参考 |
| Cookie 获取 | **自动读取**（自写脚本从浏览器本地库读，绕过 f2 限制），失败则回退手动粘贴 |
| 下载内容 | **只下视频**（不下封面/文案/原声） |
| 批量默认上限 | **20 条**，界面可选"全部" |
| 文件命名 | `{日期}_{作者}_{文案}`（需清理非法字符） |
| 增量下载 | **要**（记录已下载 ID，跳过重复） |
| 日期筛选 | **要**（界面提供起止日期，映射到 f2 的 `--interval`） |

### 命名模板落地说明
f2 的 `naming` 模板值：`{create}_{nickname}_{desc}`
- `{create}` → 日期，`{nickname}` → 作者，`{desc}` → 文案
- ⚠️ 文案含 `/ \ : * ? " < > |` 等字符会导致文件名非法，需在 `core.py` 中做 sanitize（替换为 `_`），并限长（建议 ≤ 80 字符）

## 三、环境事实（已实测）

- Python：建议使用项目 `.venv`，版本需满足 >=3.10（已验证 Python 3.13）
- 已装：requests 2.34.2、numpy、opencv-python-headless、pillow
- **未装**：f2、flask、curl_cffi、httpx、PyInstaller 等
- 安装依赖时使用项目解释器：`.venv/Scripts/python.exe -m pip install -e ".[dev]"`
- ffmpeg 未安装（本方案不依赖，仅下载原始视频）

## 四、f2 关键 API（已从官方文档核实，非臆造）

```python
from f2.apps.douyin.handler import DouyinHandler
from f2.apps.douyin.utils import SecUserIdFetcher, AwemeIdFetcher

kwargs = {
    "headers": {"User-Agent": "...", "Referer": "https://www.douyin.com/"},
    "proxies": {"http://": None, "https://": None},
    "cookie": "YOUR_COOKIE",
    "timeout": 10,
    "path": "Download",
    "mode": "post",
    "naming": "{create}_{desc}",
}
handler = DouyinHandler(kwargs)

# 单视频
detail = await handler.fetch_one_video(aweme_id="7294994585925848359")   # PostDetailFilter

# 主页批量（异步生成器，必须 async for）
async for page in handler.fetch_user_post_videos(sec_user_id, 0, 0, 20, None):
    ...

# 链接 → ID
sec_uid   = await SecUserIdFetcher.get_sec_user_id(raw_url)
aweme_id  = await AwemeIdFetcher.get_aweme_id(raw_url)

# Filter 对象：._to_raw() / ._to_dict() / ._to_list()
```

**f2 依赖清单（21 个，来自 pyproject.toml）**，打包需重点照顾这几个：
`gmssl`、`PyExecJS`、`cryptography`、`pydantic`、`httpx`、`protobuf`、`jsonpath-ng`、`m3u8`、`browser_cookie3`
另需 **`f2/conf/` 目录与签名用 `.js` 文件**作为数据文件一并打包。

## 六、核心模块设计

### config.py
- `load_config() -> dict`：从 **exe 同级目录** 的 `config.yaml` 读；不存在则创建默认
- `save_config(cfg)`：写回
- `get_app_dir() -> Path`：**打包兼容关键函数**——用 `sys.frozen` 判断是否打包环境，返回 exe 所在目录而非 `_MEIPASS` 临时目录
- Cookie 存 `config.yaml`（不进 git）

### core.py
```python
async def download_one(url_or_id: str, cfg: dict, on_progress=None) -> dict
async def download_user_posts(url: str, cfg: dict, on_progress=None, max_counts=None) -> dict
def build_kwargs(cfg: dict) -> dict          # 组装 f2 kwargs
```
- 统一处理：短链解析 → ID 提取 → 调 f2 handler → 下载 → 回调进度
- 支持取消（`asyncio.Task` + 标志位）
- 异常包装成友好中文提示（Cookie 失效 / 风控 / 无权限）

### web_app.py
| 路由 | 方法 | 作用 |
|---|---|---|
| `/` | GET | 主页面 |
| `/api/config` | GET/POST | 读/写 Cookie、下载目录、代理 |
| `/api/parse` | POST | 仅解析链接，返回作品元信息预览 |
| `/api/download` | POST | 提交下载任务，返回 `task_id` |
| `/api/progress/<task_id>` | GET | **SSE 流式推送进度** |
| `/api/tasks` | GET | 任务列表 |
| `/api/cancel/<task_id>` | POST | 取消任务 |

- 任务用内存字典 + `threading`/`asyncio` 管理
- **安全约束**：只绑 `127.0.0.1`，随机端口；`/api/download` 只接受抖音域名白名单（防 SSRF）

### main.py
- 检测打包环境 → 设工作目录 → 起 Flask（`127.0.0.1:随机端口`）→ `webbrowser.open()` → 保持运行

## 七、打包方案（重点，这里有真实的坑）

**⚠️ 已知风险**：f2 官方项目曾**明确放弃打包 exe**，因为配置路径错乱、`conf_manager` 报错、动态导入丢失。所以打包必须显式配置，不能裸跑 `pyinstaller`。

### spec 文件关键配置
```python
# douyin_tool.spec 要点
datas = [
    (collect f2/conf/*, 'f2/conf'),                    # f2 配置目录
    (collect f2 下的 *.js, 'f2/apps/douyin'),           # 签名脚本
    ('web', 'web'),                                     # 前端资源
]
hiddenimports = [
    'f2', 'f2.apps.douyin.handler', 'f2.apps.douyin.utils',
    'f2.apps.douyin.crawler', 'f2.apps.douyin.dl',
    'gmssl', 'PyExecJS', 'cryptography', 'jsonpath_ng',
    'pydantic', 'httpx', 'websockets', 'browser_cookie3',
    'importlib_resources', 'm3u8', 'protobuf',
]
# 推荐直接用 collect_all 一次收干净：
from PyInstaller.utils.hooks import collect_all
for pkg in ['f2', 'gmssl', 'PyExecJS', 'jsonpath_ng', 'browser_cookie3']:
    d, b, h = collect_all(pkg); datas += d; binaries += b; hiddenimports += h
```
打包命令：`pyinstaller build/douyin_tool.spec --onefile --noconsole`

### 降级策略（务必按此顺序）
1. 先跑通 **Python 源码版**（`python -m src.main`）——确认功能全对
2. 再打包 **onedir（文件夹版）** 调试——报错看得见、好排查
3. 确认无误后出 **onefile（单文件）**——最终交付
4. 若 onefile 因 f2 数据文件丢失而失败：改用 `--add-data` 精确补 `f2/conf`；仍失败则**交付 onedir 绿色版 zip**（功能完全一致）

## 十、风险与对策

| 风险 | 对策 |
|---|---|
| **f2 打包路径错乱**（官方曾因此放弃 exe） | `get_app_dir()` 用 `sys.frozen` 判断；配置放 exe 同级；spec 精确 add-data |
| **签名脚本/conf 未打进包** | spec 中用 `collect_all('f2')` 全量收集 |
| **Cookie 失效**（f2 的 `--auto-cookie` 因 Chrome V20 加密已失效） | 网页里做 Cookie 粘贴框，持久化到 `config.yaml`，失效给明确提示 |
| **风控限流**（返回空但 HTTP 200） | 内置请求间隔、支持配代理、失败提示"换 IP/降频" |
| **f2 版本 breaking change** | 锁 `requirements.txt` 版本区间，README 注明升级方式 |
| **杀软误报 exe** | 提供免安装 zip + 源码版；必要时建议加白名单 |
| **Windows 中文路径/编码** | 全用 `pathlib`，输出用 `utf-8`，避免 shell 拼接 |
| **端口占用** | 随机端口 + 失败重试 |
